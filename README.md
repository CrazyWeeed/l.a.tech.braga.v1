# L.A. Tech Solutions

Criar o site completo “L.A. Tech Braga” com visual premium, minimalista escuro e foco total em conversão para assistência informática ao domicílio em Braga.

────────────────────

OBJETIVO PRINCIPAL:

Criar uma landing page moderna, tecnológica e profissional que transmita confiança, rapidez e atendimento técnico local.

O site deve parecer premium e limpo, evitando aparência de template genérico, gamer ou sci-fi exagerado.

────────────────────

ASSETS FORNECIDOS:

“la background”
→ usar como fundo principal da hero

“logo (2).png”
→ usar como logo principal da hero
→ preservar transparência real
→ remover qualquer fundo restante se existir

────────────────────

PALETA DE CORES:

Preto profundo: #0B0B0F

Branco gelo: #F6F6F7

Cinza escuro: #1A1A22

Cinza médio: #8A8A93

Cinza claro: #E6E6EA

Laranja principal: #FF5A1F

Laranja hover: #FF8A5B

────────────────────

ESTILO VISUAL:

minimalista premium

dark mode elegante

tecnologia moderna e limpa

sem poluição visual

sem fotos de pessoas

sem excesso de glow

sem estética gamer

────────────────────

HEADER / TOPO:

header fixo minimalista

fundo semi-transparente escuro com blur leve

logo pequena no canto esquerdo

botão WhatsApp discreto no topo

garantir que a hero tenha padding-top suficiente para não ficar escondida atrás do header

────────────────────

HERO (LANDING PRINCIPAL):

A hero deve ocupar aproximadamente 100vh e conter:

background

logo principal

bloco “TECH BRAGA”

subtítulo

botão WhatsApp

botão Ver serviços

Todos os elementos centralizados verticalmente.

────────────────────

BACKGROUND DA HERO:

Usar “la background”:

cover full screen

aplicar overlay preto para escurecer aproximadamente 20%

estética geométrica tecnológica escura

manter profundidade premium

────────────────────

LOGO PRINCIPAL:

Usar “logo (2).png”:

centralizado

elemento dominante da hero

tamanho grande mas equilibrado

fundo transparente obrigatório

aplicar apenas micro glow branco gelo MUITO sutil:
cor: #F6F6F7
blur leve
opacidade baixa

NÃO usar glow exagerado

NÃO usar neon forte

────────────────────

BLOCO “TECH BRAGA” (ABAIXO DA LOGO):

“TECH”

neon laranja vibrante

cor: #FF5A1F

“BRAGA”

metálico prata/cromado

reflexos sutis

aparência premium

ABAIXO:
“ASSISTÊNCIA INFORMÁTICA AO DOMICÍLIO”

branco gelo

elegante

minimalista

linhas horizontais finas discretas nas laterais

IMPORTANTE:

aparência premium moderna

não parecer gamer

alta legibilidade

────────────────────

SUBTÍTULO:

cor: #E6E6EA

────────────────────

CTA PRINCIPAL:

Botão:
“Chamar no WhatsApp”

centralizado

aparência premium

Botão secundário:
“Ver serviços”

outline discreto

────────────────────

PARALLAX (OBRIGATÓRIO):

A hero deve ter parallax baseado em scroll real.

IMPORTANTE:

nenhum elemento pode flutuar sozinho

animação apenas durante scroll

MOVIMENTO:

background: 2–4%

logo principal: 10–15%

TECH BRAGA: 5–7%

subtítulo: 5–7%

botões: 5–7%

Todos os elementos devem se mover suavemente em profundidades diferentes.

────────────────────

FADE OUT DA HERO:

Ao descer a página:

hero deve desaparecer suavemente

fade deve afetar SOMENTE a hero

iniciar cedo (~20% scroll)

desaparecer completamente antes da segunda seção

transição suave para próxima seção

NUNCA apagar o restante do site.
