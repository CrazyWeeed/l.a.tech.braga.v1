# L.A. Tech — pós-publicação

Depois de publicar este arquivo na Vercel:

1. No Google Search Console, mantenha `https://www.la-tech.pt/` como propriedade e envie `https://www.la-tech.pt/sitemap.xml`.
2. Use Inspeção de URL para testar a homepage e as cinco novas páginas de serviço; peça indexação depois de confirmar que cada URL responde com 200 e a versão canónica está correta.
3. Não altere novamente Title/H1 por alguns dias. O objetivo é primeiro medir se as consultas já fortes (`computer repair`, `laptop repair`, `motherboard repair`) mantêm a posição enquanto aumentam os cliques.
4. Compare separadamente Portugal e todos os países. A referência atual é o período 19–29/08/2026 fornecido na conversa: 1,23 mil impressões, 2 cliques, CTR 0,2% e posição média 5,2.
5. Acompanhe sobretudo as novas consultas portuguesas: `informática braga`, `assistência informática braga`, `reparação computadores`, `reparação portáteis` e variações locais que aparecerem no Search Console.
6. Verifique Core Web Vitals e desempenho mobile depois que a Vercel gerar os assets finais. As imagens do projeto foram reduzidas e a primeira imagem do hero passou a usar preload responsivo.

Importante: não adicionar endereço de rua, coordenadas, avaliações, links sociais ou promessas de serviço ao Schema sem que esses dados existam de facto no negócio.
